What This Agent Detects

🐛

Bug Detection

Identifies null pointer exceptions, off-by-one errors, infinite loops, unhandled exceptions, and logic flaws.

🔐

Security Vulnerabilities

Detects SQL injection, XSS, hardcoded credentials, insecure deserialization, and OWASP Top 10 issues.

👃

Code Smell Detection

Flags long methods, duplicate code, God classes, magic numbers, and other maintainability anti-patterns.

Severity Classification

Each issue is rated Critical, High, Medium, Low, or Info with a full explanation of the risk level.

💡

Suggested Improvements

Provides concrete, copy-paste-ready code fixes with explanations of why the change improves the code.

📊

Quality Score

Calculates an overall quality score (0–100) based on severity-weighted issues across all detection categories.
